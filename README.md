# Peg Counter
Pick beer (type your own ml and alcohol %) or hard spirits (30/60 ml, type your own %), tick a box per peg, see live alcohol units and % of the weekly safe limit, save sessions, and view weekly reports.
Push to `main` -> GitHub Actions builds the APK (Actions tab -> latest run -> Artifacts).
Assumptions are at the top of `Data.kt` (default spirits %, limit 14 units/week).
